Privacy Policy

PacePal Bot

How PacePal Bot handles data when it watches for mentions, finds Twitch links, and displays live speedruns from therun.gg.

Last updated 2026-06-24

01 Introduction

This Privacy Policy explains how PacePal Bot ("the Bot", "we", "us") collects, uses, and stores data when you or your Discord server interact with it. The Bot is operated by an individual developer, Franck.

PacePal Bot watches for messages in which it is mentioned, looks for Twitch links in those messages, and — if the linked Twitch user is tracking a speedrun on therun.gg — displays their live run in a message that the Bot keeps updated. If no tracked run is found, the Bot does nothing further.

If you have any questions about this policy or your data, contact us at franck+pacepal-bot@michea.dev.

02 Data We Collect

PacePal Bot is designed to collect as little data as possible. The data it handles falls into the following categories.

Data processed but not stored

  • Message content of messages that mention the Bot. When the Bot is mentioned, it reads that message to find Twitch links. The Bot does not use Discord's Message Content privileged intent; it only receives the content of messages in which it is explicitly mentioned. This content is processed in memory to extract links and is then discarded. It is not stored long term. Message content may appear briefly in temporary operational/debug logs, which are short-lived and not retained.

Data stored persistently

  • Twitch / therun.gg username — the public Twitch username taken from a link. It is stored to hold per-runner configuration (including customized display configuration for that runner) and to keep track of runs in progress, so that an active run can be resumed after the Bot restarts.
  • therun.gg split file name — the identifier of the run/splits associated with a runner, stored as part of that runner's configuration.
  • Server and display configuration — settings provided by Discord users and server administrators that control how the Bot operates and how runs are displayed (for example, which channel to post in and display preferences). This configuration may include Discord identifiers (such as server and channel IDs) necessary for the Bot to function.

The Twitch username and split file name are obtained from public sources (a posted link and therun.gg's public run data). A Twitch username may identify the runner, so we treat it as personal data and retain it only as described in Data Retention below.

The Bot does not collect message logs, member lists, presence data, or voice data, and does not use any privileged intents.

03 Why We Collect This Data

  • Twitch / therun.gg usernames and split file names are required to provide the Bot's core function: finding and displaying a runner's live run, tracking which splits belong to each runner, and resuming runs in progress after the Bot restarts.
  • Server and display configuration is required so the Bot knows where and how each server wants runs displayed.

We do not use your data for advertising, profiling, or analytics, and we do not sell it.

04 Legal Basis for Processing (GDPR)

For users in the EU, UK, and EEA, our legal basis for processing the above data is legitimate interest: the Bot needs this data to provide the functionality that a server has voluntarily chosen to use by adding the Bot and configuring it. Where configuration is supplied by a server administrator or user, that supply constitutes a deliberate request for the Bot to operate as configured.

You may object to this processing at any time (see Your Rights below).

05 Data Storage and Security

  • The Bot and its database run on private infrastructure located in France.
  • Connections between the Bot and both Discord and therun.gg are encrypted in transit.
  • Stored configuration runs on servers with encryption enabled.
  • Access to the infrastructure and the database is restricted to the operator only. The infrastructure is locked down and not accessible to any third party.
  • All supporting services used for operating the Bot (such as error monitoring) are self-hosted on the same private infrastructure.

06 Data Retention

  • Message content is not retained. It is processed in memory and discarded; any appearance in temporary debug logs is short-lived.
  • Configuration data (Twitch/therun.gg usernames, split file names, and server/display settings) is retained while the Bot is in use by a server and is deleted within 30 days of the Bot being removed from that server.
  • A runner whose username and run data are displayed by the Bot may request removal of that data at any time, independently of whether the Bot remains in a server (see Your Rights below).
  • You may request earlier deletion at any time (see below).

07 Data Sharing and Third Parties

PacePal Bot shares data with only one third party:

  • therun.gg — the Bot queries therun.gg using the public Twitch username found in a link to look up run data. No Discord user data or other personal data is sent to therun.gg; only the public Twitch handle is used for the lookup. therun.gg's own handling of your data is governed by their Privacy Policy.

No other third parties receive your data. All other supporting services are self-hosted. We do not use external analytics providers, external AI providers, or payment processors. The Bot is free and has no paid tier.

The public Twitch username processed by the Bot originates from a link posted in Discord; the Bot does not contact Twitch or send any data to it. Your use of Twitch is governed by Twitch's own Privacy Notice.

The Bot necessarily operates on the Discord platform, and your use of Discord is governed by Discord's own Privacy Policy.

08 Your Rights

Depending on your location, you may have rights to access, correct, delete, or object to the processing of your data. You can:

  • Request a copy of the data we hold relating to you or your server.
  • Request deletion of your data.
  • Object to processing based on legitimate interest.

To exercise any of these rights, contact franck+pacepal-bot@michea.dev. We currently handle these requests by email; there is no in-Bot deletion command at this time. We will respond within a reasonable period and in any case within the timeframes required by applicable law.

You can also stop the Bot from processing your data by removing it from your server, after which stored configuration is deleted within 30 days as described above.

If you are a runner whose username or run data is displayed by the Bot and you want it removed, contact franck+pacepal-bot@michea.dev. We will remove your username and associated run/split data from our configuration on request, regardless of whether the Bot remains in the server that added you.

09 Children's Privacy

PacePal Bot is not intended for children under 13 (or the higher minimum digital-consent age in your country), consistent with Discord's Terms of Service. We do not knowingly collect data from children under this age. If you believe we have inadvertently collected such data, contact franck+pacepal-bot@michea.dev and we will delete it promptly.

Significant changes may also be announced through the Bot's support channels. Continued use of the Bot after changes take effect constitutes acceptance of the updated policy.
